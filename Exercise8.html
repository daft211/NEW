Responsive Page with Sprite Navigation

How this page was made responsive

Key techniques used:

  • Viewport meta tag – <meta name="viewport" content="width=device-width, initial-scale=1.0"> so the browser sizes the page to the device.
  • Fluid images – width: 100%; height: auto; so images scale with their container.
  • Flexbox with flex-wrap – the navigation and the two-image gallery use display: flex + flex-wrap: wrap so items can reflow.
  • Media queries – at 640px and below the nav switches to a vertical stack and dropdowns become static (inline) for better touch usability.
  • Flexible basis – flex: 1 1 280px on the image figures lets them sit side-by-side on wide screens and stack on narrow ones.

CSS Flexbox vs CSS Grid – when to use which

Flexbox (Flexible Box Layout) is a one-dimensional layout system. It is ideal for arranging items in a single row or a single column (navigation bars, toolbars, card rows, centering content). You control alignment, distribution of free space, and wrapping along one axis.

CSS Grid is a two-dimensional layout system. It is ideal when you need both rows and columns at the same time (full page layouts, photo galleries with precise placement, complex dashboard grids). You define tracks (rows and columns) and place items into cells or areas.

Why choose one over the other?

  • Use Flexbox when the layout is mainly linear (this navigation bar and the simple two-image row are perfect Flexbox candidates).
  • Use Grid when you need explicit control over both dimensions, overlapping items, or named template areas (e.g., a full site skeleton with header / sidebar / main / footer).
  • They work well together: Grid for the overall page structure, Flexbox for the components inside each grid area.
